# ComfyUI-DINKIssTyle-3D-Pose 개발 계획

상태: 첫 구현 및 기능 강화 완료. 2026-10-15. 원래 설계와 구현 내역을 함께 보관한다.

모델 품질의 후속 개선: 절차적 단면/표면 합성 방식 대신 MakeHuman CC0 베이스 메쉬와 직접 제작된 가중치를 포함했다. 원본 관절 위치로 바인딩하고 52개 포즈 컨트롤로 연결하며, 사각형 토폴로지의 Catmull-Clark 세분화 1단계를 사용한다. 렌더 버전은 dkst-pose-5-makehuman이다.

기능 강화의 설계와 구현 상태는 [PLAN_V2.md](PLAN_V2.md)에 정리했다. 연속 스키닝 메쉬, 포즈 레퍼런스 가이드, 깊이맵, 박스 오브젝트와 35mm 환산 렌즈/카메라 텍스트 출력이 대상이다.

바닥/상세 표현 개선: 렌더 버전 dkst-pose-3-three-180. 바닥은 주/보조 격자가 있는 원근 그리드로 출력하며, OpenPose에는 선택적으로 투영 그리드를 표시한다. Simplify hands / Simplify feet로 메쉬를 하나의 형태로 표시하고, 단순한 손은 OpenPose 손가락을 생략한다. 상세 관절 회전은 보존하고 숨겨진 형상은 선택/인체 맞춤/바닥 정렬에서 제외한다. 얼굴은 곡면을 따라가는 중심선과 눈썹 기준선이다. 이전 v1/v2 장면은 상세 표현 기본값을 채워 v3로 이전한다. Python 52개와 JS 19개, 브라우저 시나리오로 검증했다.

OpenPose 확장 구현: DKST_3D_Pose의 세 번째 pose 출력과 별도 DKST_3D_OpenPose 노드를 추가했다. 같은 촬영 카메라로 COCO-18 몸/양손 21점씩을 투영하고 렌더 PNG와 함께 불변 데이터로 저장한다. 변환 노드는 IMAGE, 정규화 POSE_KEYPOINT 프레임 목록, 픽셀 좌표 OpenPose JSON 문자열을 출력한다. 70점 얼굴 표정 데이터와 BODY_25는 범위 밖이다. Python 47개, JS 15개 및 OpenPose 연결을 포함한 브라우저 시나리오를 검증했다.

인터페이스 언어는 사용자의 추가 요구에 따라 영어로 통일했다. 버튼·설정·관절 이름·프리셋·안내·오류 메시지에 적용했으며 브라우저 검사에서 확인했다.

모델 품질 개선: 최초 타원체 조합을 부위별 곡면 메시로 교체하고 성인 등신의 팔 길이·몸통/다리 길이·어깨/골반 폭을 재조정했다. 흉곽/허리, 턱/두상, 팔다리의 테이퍼, 손과 발, 출력에 남는 실제 관절 연결부를 구성했다. 모델 버전은 dkst-pose-2-three-180이며 최초 버전의 장면은 관절/카메라 값 유지 후 브라우저에서 자동 갱신한다. JS 자동 검사에는 팔 길이와 손목 위치, 곡면 노멀/지면, 이전 장면 이전 검증을 추가해 총 10개가 있다.

구현한 파일과 사용법은 README.md에 정리했다. 독립 노드, 6종 등신, 몸/손가락 FK, 손발 IK와 굽힘 핸들, 카메라 외부 조작/카메라뷰 이동, 촬영 미리보기, 8종 프리셋, 장면 저장/복원, IMAGE/MASK 출력이 포함된다. 카메라와 포즈 제어는 별도 camera_controls.js/pose_controls.js 대신 editor.mjs와 rig.mjs에 구성했다. 기본 포즈 데이터는 state.mjs에 정의했다.

자동 검증: Python 백엔드 30개, JS 모델/상태/IK 7개 및 실제 WebGL 브라우저 시나리오. 브라우저 시나리오는 독립 하네스에서 실제 편집기·업로드·텐서 출력을 사용하며, 사용자의 실제 ComfyUI 설치에서의 최종 확인은 남아 있다.

## 목표와 패키지 경계

ComfyUI 안에서 3D 인체의 비율과 관절을 편집하고, 지정한 촬영 카메라의 이미지를 IMAGE로 출력하는 독립 커스텀팩을 만든다.

- 개발 위치: 이 저장소의 `ComfyUI-DINKIssTyle-3D-Pose/`.
- 설치 위치: `ComfyUI/custom_nodes/ComfyUI-DINKIssTyle-3D-Pose/`.
- 이 폴더만 복사해 설치할 수 있도록 자체 노드 등록, 웹 확장, 의존성 및 설명서를 갖춘다. 상위 팩의 모듈을 직접 import하지 않는다.
- 초기 노드: `DKST 3D Pose`. 편집기 열기 버튼, 등신 선택, 출력 크기, 마지막 출력 미리보기를 제공한다.
- 기본 출력: `IMAGE`와 `MASK`. IMAGE는 RGB, MASK는 ComfyUI의 관례에 따라 투명 배경이 1인 마스크로 정의한다. 불투명 출력은 MASK가 0이다.
- 첫 구현의 설치와 사용은 README.md를 따른다.

## 모델과 등신

첫 모델은 구·타원체·연결 부위로 만든 입체 마네킹으로 제안한다. 관절 계층을 따라 각 부품이 움직이며, 모델 파일을 내려받지 않고 생성할 수 있다. 추후 스킨 메시 모델을 붙일 수 있도록 관절 이름과 모델 생성 코드를 분리한다.

- 선택값: **2 / 3 / 6 / 7 / 8 / 9 등신**.
- 등신은 중립 자세의 머리 높이에 대한 머리 꼭대기~발바닥 높이의 비율로 정의한다. 포즈에 따라 바뀌는 화면상 높이로 계산하지 않는다.
- 공통 기준 신장을 두고 등신에 따라 머리 크기와 몸통·골반·팔·다리 길이를 재배분한다.
- 2·3등신은 큰 머리와 짧은 몸통·팔다리를 가진 별도 비율 표를 쓴다. 6~9등신 모델을 균일 축소하는 방식으로 만들지 않는다.
- 비율을 바꿀 때 관절 회전은 유지하고 연결 위치와 길이를 갱신한다. 손·발 IK 목표가 있다면 새 비율에서 다시 계산한다.
- 기본 재질은 무광 회색. 배경색과 기본 조명을 조절할 수 있게 한다.

## 관절 편집

몸 전체 이동·회전과 각 관절의 로컬 회전을 구분한다. 내부 회전 저장은 quaternion, 사용자 입력은 도 단위로 표시한다.

| 영역 | 제어 대상 |
|---|---|
| 중심 | 루트, 골반, 허리, 가슴 |
| 머리 | 목, 머리 |
| 팔 | 좌우 쇄골, 어깨, 팔꿈치, 손목 |
| 다리 | 좌우 고관절, 무릎, 발목, 발가락 기저부 |
| 손 | 좌우 엄지·검지·중지·약지·소지의 굽힘 관절 |

- 화면 클릭 또는 관절 목록으로 선택한다. 가려진 관절도 목록에서 선택할 수 있다.
- 회전 기즈모와 숫자 입력을 제공한다. 관절 선택 시 로컬 축과 이름을 표시한다.
- 관절별 가동 범위 제한을 기본 적용하고, 과장된 포즈를 위해 제한 해제 옵션을 제공한다.
- 왼쪽/오른쪽 복사, 포즈 좌우 반전, 선택 관절 초기화, 전체 초기화, 실행 취소/다시 실행을 제공한다.
- 먼저 FK(선택 관절 회전)를 완성한 뒤 손·발 목표점을 이동하는 팔/다리 IK와 팔꿈치·무릎 방향 핸들을 추가한다. IK와 FK는 동일한 관절 회전 상태에 반영한다.
- 기즈모 조작 중 시점 회전을 잠그고, 편집기 마우스 입력이 ComfyUI 그래프 이동으로 전달되지 않게 한다.

손가락 세부 제어까지 첫 정식 버전의 범위에 포함하되, 몸 전체 편집이 동작하는 중간 결과부터 검증한다. 표정·눈·입 변형은 이후 확장 범위다.

## 얼굴 방향 표시

- 머리 정면 표면에 `+`를 붙이고 머리 회전을 그대로 따른다.
- 마커는 깊이 가림을 적용해 뒤통수에서 비쳐 보이지 않게 한다.
- 작은 코 돌출부를 함께 사용해 측면 방향을 구분한다.
- 기본 출력에도 `+`를 포함한다. 출력에서 얼굴 표시를 끄는 옵션을 제공한다.
- 관절 표시·기즈모·카메라 가이드는 편집용으로만 표시한다.

## 편집기와 두 시점

노드에는 가벼운 출력 미리보기를 두고, 버튼으로 큰 편집 패널을 연다. 데스크톱에서는 큰 3D 뷰, 관절/속성 패널, 작은 촬영 카메라 미리보기를 함께 배치한다. 작은 화면에서는 패널을 접을 수 있게 한다.

**편집 시점**은 장면을 자유롭게 둘러보는 시점이다. **촬영 카메라**는 최종 출력 구도를 결정한다. 두 상태를 독립 저장한다.

| 모드 | 조작과 결과 |
|---|---|
| 외부 편집 | 인체와 촬영 카메라를 밖에서 본다. 카메라 본체·촬영 범위 가이드를 선택해 위치와 회전을 조절한다. |
| 카메라 보기 | 메인 캔버스를 촬영 카메라 화면으로 전환한다. 잠금 상태에서는 포즈를 편집해도 카메라가 움직이지 않는다. |
| 카메라 보기 + 조작 | 명시적으로 잠금을 해제해 촬영 카메라를 궤도 회전·팬·돌리 또는 이동 키로 움직인다. 원근 카메라의 이동 키 조작부터 지원한다. |
| 현재 시점 적용 | 편집 시점의 구도를 촬영 카메라로 복사한다. |

- 정면·후면·좌측·우측·위쪽 보기와 선택 대상 맞춤을 제공한다.
- 촬영 카메라: 위치, 회전, 대상 중심, 원근/직교, FOV 또는 직교 크기, 출력 화면비.
- 카메라 이동과 FOV 변경을 구분한다. 직교에서는 앞뒤 이동 대신 직교 크기로 확대·축소한다.
- 카메라를 외부에서 조절할 때 작은 촬영 미리보기는 실시간으로 갱신한다.
- 미리보기와 출력은 동일한 카메라·화면비를 사용한다. 출력 영역 밖은 여백 또는 어두운 영역으로 표시한다.
- 편집용 그리드와 바닥 가시성은 출력용 바닥 설정과 구분한다.

## 기본 포즈 프리셋과 저장

초기 프리셋: T-pose, A-pose, 편하게 서기, 의자에 앉기 자세, 쪼그려 앉기, 걷기, 달리기, 한 팔 들기.

- 프리셋은 관절 회전 데이터로 정의해 모든 등신에서 재사용한다. 필요한 경우 등신별 보정을 추가한다.
- 포즈 선택으로 카메라를 초기화하지 않는다. 인체 맞춤은 별도 버튼으로 실행한다.
- 앉기 프리셋은 인체 자세만 제공하며 의자 소품은 이후 범위다.
- 사용자 포즈 JSON 저장/불러오기, 카메라까지 포함한 장면 JSON 저장/불러오기를 구분한다.
- 워크플로에 스키마 버전, 모델 비율, 루트 변환, 관절 회전, 촬영 카메라, 조명·배경, 출력 설정을 저장한다.
- 편집 시점 같은 UI 상태도 복원하되 최종 출력 캐시 판정에서는 제외한다.

## 렌더링과 ComfyUI 실행 연결

제안 구성: 브라우저의 Three.js/WebGL이 편집과 이미지 생성을 담당하고 Python이 저장된 렌더 결과를 검증해 IMAGE/MASK로 변환한다. Three.js와 필요한 addon은 버전을 고정해 로컬 번들로 배포한다.

렌더 흐름:

1. 편집기에서 장면을 변경하고 실시간 촬영 미리보기를 갱신한다.
2. 적용 시 출력 해상도로 별도 렌더하고 PNG를 서버에 저장한다.
3. 실행 요청 직전에 적용되지 않은 변경이 있으면 렌더·업로드 완료까지 기다린다.
4. 해당 실행의 장면 상태와 렌더 식별자를 고정한다. 이후 편집은 다음 실행에 적용한다.
5. Python 노드가 장면 해시·크기·렌더 식별자를 확인하고 이미지 및 마스크 텐서를 반환한다.

장면 해시는 정규화한 모델·포즈·카메라·조명·배경·크기와 렌더러/모델 버전으로 계산한다. 편집 시점이나 선택 관절은 포함하지 않는다. 오래된 비동기 응답이 최신 상태를 덮어쓰지 않도록 장면 변경 번호도 확인한다.

- 렌더 결과 저장은 재실행과 서버 재시작에 사용할 수 있는 지속 파일로 한다. 변경 가능한 노드 ID 대신 불변 렌더 식별자를 사용한다.
- 장면 변경 시 ComfyUI 실행 캐시가 무효화되도록 장면 상태/해시를 실제 노드 입력에 포함한다.
- 실패 또는 렌더 불일치 시 이전 이미지를 조용히 반환하지 않고 재렌더가 필요한 이유를 표시한다.
- 워크플로를 다른 서버로 옮겼을 때 PNG가 없다면 브라우저에서 저장된 장면으로 다시 렌더한다.
- API 단독 실행은 이미 저장된 렌더 결과를 사용할 수 있다. 새로운 장면 JSON만으로 서버에서 렌더하는 기능은 서버 렌더러를 추가하는 이후 단계다.
- 렌더 크기는 미리보기 DOM 크기와 분리하고, 투명 배경·색공간·안티앨리어싱을 명시한다.
- 업로드 크기와 경로를 검증하고 팩 전용 저장 영역을 사용한다.
- 닫힌 편집기와 삭제된 노드의 renderer, 이벤트, 재질·geometry 등을 정리한다. 작은 노드 미리보기마다 WebGL 컨텍스트를 만들지 않는다.

실행 전 비동기 렌더 연결 방식과 현재 ComfyUI 프런트엔드 호환성은 첫 프로토타입에서 확인한다. 이전 팩의 업로드/실행 전처리 경험은 참고하되 직접 의존하지 않는다.

## 구현 순서와 완료 기준

1. **연결 프로토타입:** 독립 팩 등록 → 임시 3D 모델 → 촬영 카메라 → PNG 저장 → IMAGE 출력. Queue 직전 상태 확정, 노드 복제, 기존 팩과 동시 설치를 확인한다. 이 단계에서 실행 연결의 기술적 불확실성을 해소한다.
2. **인체와 FK:** 6종 등신, 몸의 관절 계층, 얼굴 `+`, 선택·회전 기즈모·숫자 입력, 범위 제한. 연결 부위가 벌어지지 않고 비율 변경 후 자세가 유지되는지 확인한다.
3. **카메라 편집:** 외부 카메라 선택과 조작, 카메라 보기/잠금/이동, 작은 촬영 미리보기, 원근/직교, 화면비. 두 편집 모드에서 같은 결과 구도가 나오는지 확인한다.
4. **포즈 작업 기능:** 손가락 제어, 팔/다리 IK, 프리셋, 반전, 초기화, Undo/Redo, JSON과 워크플로 복원. 2·3등신에서도 프리셋 및 IK가 안정적으로 동작하는지 확인한다.
5. **출력과 배포:** 조명·배경·투명도, MASK, 오류 처리, 자원 정리, 독립 설치 안내와 예제 워크플로.

최종 검증은 장면 저장/복원, 최신 포즈 출력, 큐 실행 중 추가 편집, 투명 마스크, 가이드 제외, 지정 해상도, 편집기 닫기/재열기, 저장 렌더 누락 복구에 집중한다. 관절 계층·반전·직렬화·캐시 판정은 자동 검사하고 화면 조작과 구도는 브라우저에서 확인한다.

## 이후 확장

OpenPose 이미지/키포인트, Depth·Normal 출력, 여러 인물, 소품, 외부 리깅 모델, 서버 렌더링, 포즈 시퀀스는 기본 편집기와 이미지 출력이 안정화된 뒤 검토한다.
